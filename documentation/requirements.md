\# Project Requirements



\## Operating System



Windows 10 or Windows 11



\## Software



\- Python 3

\- PowerShell

\- Git

\- GitHub account



\## Python Dependencies



No external Python packages are required.



The project uses Python standard library modules including:



\- pathlib

\- shutil

\- csv

\- datetime

\- json

\- collections



\## Optional Tools



\- Microsoft Copilot

\- Windows Task Scheduler



\## Test Environment



The project was developed and tested using:



C:\\Automation-Test



Using a separate test folder prevents the automation from changing personal files during development.
